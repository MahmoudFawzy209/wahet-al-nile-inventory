# برنامج إدارة مخزون ومشتريات مطعم المندي والمأكولات اليمنية 🇾🇪 🇪🇬

نظام مبسط، عملي، وسريع لإدارة وتتبع المواد الخام والمستلزمات، فواتير المشتريات، المنصرف للمطبخ، والتالف، مع إمكانية التصدير الاحترافي إلى Microsoft Excel والطباعة المباشرة على مقاس A4.

---

## 🌟 أبرز مميزات النظام

1. **لوحة مؤشرات رئيسية (Dashboard):**
   - إجمالي عدد الأصناف في المخزن.
   - عدد الأصناف التي أوشكت على النفاد (تنبيه الحد الأدنى).
   - عدد الأصناف النافدة تماماً (رصيد 0).
   - إجمالي القيمة التقديرية الحالية للمخزون (ج.م).
   - جدول لآخر المشتريات المسجلة وجدول لآخر حركات الاستهلاك والتالف.

2. **إدارة المواد والمخزون:**
   - جدول تفصيلي للمواد مع إمكانية البحث الفوري بالاسم أو المورد أو الملاحظات.
   - تصفية سريعة حسب التصنيف وحالة المخزون (متوفر، منخفض، نافد).
   - إضافة مادة جديدة، تعديل بيانات أي مادة، أو حذفها بسهولة.

3. **تسجيل المشتريات:**
   - تسجيل كميات التوريد وسعر الوحدة والمورد.
   - زيادة الرصيد تلقائياً في المخزن مع إعادة حساب متوسط سعر التكلفة المرجح.

4. **تسجيل الاستهلاك والتالف:**
   - خصم الكميات المستخدمة للطهي في المطبخ أو الهدر والتالف.
   - تنبيه فوري في حال كانت الكمية المخصومة أكبر من الرصيد المتوفر لمنع الرصيد السالب دون تأكيد.

5. **تصدير Excel احترافي (.xlsx) والطباعة:**
   - تصدير كامل بيانات المخزون مع التنسيق باللغة العربية (RTL).
   - الأعمدة مرتبة بدقة حسب متطلبات إدارة المطعم.
   - تمييز النواقص باللون الأصفر والنافد باللون الأحمر.
   - إمكانية تصدير ملف شامل يحتوي على 3 أوراق عمل (المخزون الحالي، سجل المشتريات، سجل الاستهلاك).
   - إمكانية الطباعة المباشرة من المتصفح على ورق A4 أفقي (Landscape).

---

## 🚀 التشغيل المحلي

```bash
# تشغيل خادم التطوير (على المنفذ 3005)
npm run dev

# أو تشغيل نسخة الإنتاج
npm run start
```

الرابط المحلي: **`http://localhost:3005`**  
رابط الشبكة المحلية (WiFi): **`http://192.168.100.5:3005`**
